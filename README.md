# Price Viewer

Минимальный каталог публичных объявлений FunPay. Запуск: `docker compose up --build -d`, затем откройте http://localhost:5000. Остановка: `docker compose down`. Данные сохраняются в Docker volume `price_data`.

Сборщик находит категории на главной странице, последовательно обходит их и сохраняет доступные на странице объявления. После полного обхода начинается следующий. `CRAWL_DELAY` задаёт паузу между запросами в секундах (по умолчанию 1), `CRAWL_INTERVAL` — паузу между проходами (300). Полный проход может занимать часы. Данные каждой категории заменяются только после успешной загрузки, при ошибках сохраняется предыдущая версия. Сайт показывает прогресс и число ошибок. Источник может ограничивать доступ или менять разметку; полнота и мгновенная актуальность не гарантируются. Собирается содержимое публичных страниц категорий, без авторизации и обхода ограничений, дополнительная подгрузка объявлений не реализована.

Поиск предлагает категории; выберите нужную, чтобы получить её фильтры FunPay. По умолчанию сохраняется порядок объявлений внутри категории, а не оценка популярности: FunPay не предоставляет общий рейтинг для разных категорий. Поиск и фильтры применяются к уже загруженным данным. При выборе ранее загруженной категории сборщик обновляет её для получения фильтров. При ограничении запросов FunPay (HTTP 429) сборщик делает паузу; обновление может задерживаться.

## Структура проекта

- `main.py` — точка входа приложения.
- `price_viewer/config.py` — настройки окружения.
- `price_viewer/database.py` — подключение к SQLite и схема данных.
- `price_viewer/search.py` — единая нормализация текста поиска.
- `price_viewer/routes.py` — HTTP-страница и API.
- `price_viewer/worker.py` — очередь и фоновое обновление.
- `price_viewer/sources/funpay.py` — получение и разбор данных FunPay.
- `templates/` и `static/` — интерфейс; `tests/` — проверки.

Поиск одинаково нормализует регистр, Unicode и транслитерирует текст. Это помогает с разными алфавитами, но не является переводом и не гарантирует сопоставление разных названий одного товара (например, произвольного русского написания английского бренда). Lolzteam и Playerok подключены для текстового поиска.

## Lolzteam

Для поиска на Lolzteam укажите `LOLZ_TOKEN` в локальном `.env` и перезапустите `docker compose up --build -d`. `.env` исключён из Git и Docker build context. Запросы к Lolzteam выполняются в фоне при текстовом поиске; результаты кэшируются на 120 секунд. За один поиск загружается не более пяти страниц API, поэтому выдача может быть неполной. При выборе конкретной категории FunPay сопоставление категорий между площадками пока не выполняется. Поиск по совпадающим словам не гарантирует, что условия товаров одинаковы. Поиск Playerok использует каталог, доступный на сайте площадки.

Категории Lolzteam появляются по мере загрузки предложений из его API. Подсказки показывают площадку, а выбор категории Lolzteam запрашивает её раздел напрямую. Категории разных площадок пока не объединяются автоматически: одноимённые названия сами по себе не подтверждают одинаковые условия товаров.

По умолчанию фоновый обход всех категорий выключен (`CRAWL_BACKGROUND=0`): это уменьшает число запросов и помогает быстрее загружать выбранные категории. Поиск по ещё не загруженным категориям поэтому остаётся неполным до их посещения. Чтобы включить обход всего каталога, задайте `CRAWL_BACKGROUND=1` в `.env` и перезапустите Compose. При ответе FunPay HTTP 429 сборщик соблюдает паузу и повторяет запрос; скорость первой загрузки зависит от доступности источника.

## Playerok

Каталог Playerok подключён через сервис, который использует сайт площадки. Текстовый поиск загружает до пяти страниц, а выбранная категория запрашивается по её идентификаторам. Ответы кэшируются на 120 секунд. Доступность и формат сервиса могут измениться; цены и наличие следует проверять на странице предложения. Сопоставление категорий между площадками пока не автоматизировано.

## Сопоставление категорий

При выборе категории приложение ищет предложения на других площадках и объединяет найденные категории, если нормализованное название игры совпадает и тип товара распознан (аккаунты, валюта, предметы, прокачка или ключи). Названия разных игр и неизвестные типы не объединяются. Категории Lolzteam, в которых тип товара не указан, автоматически не объединяются: их можно искать по тексту. Набор доступных категорий зависит от уже полученных ответов источников; запросы ограничены первыми пятью страницами. Специальные фильтры FunPay применяются только к объявлениям с соответствующими атрибутами.

## Plati.Market

Текстовый поиск Plati.Market работает через публичный каталог, до двух страниц по 30 товаров на запрос. Для карточек дополнительно загружаются положительные и отрицательные отзывы о товаре; это не рейтинг продавца. Данные загружаются в фоне и кэшируются на 120 секунд, а ссылки ведут на страницы товаров Plati.Market. Категории Plati.Market пока не сопоставляются с категориями других площадок; используйте текстовый поиск. На стороне источника данные и доступность могут измениться.
